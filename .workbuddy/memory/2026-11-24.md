## 修复 Vite 开发服务器无法访问
- 现象：运行 `npm run dev` 后浏览器访问失败。复现发现 Vite 根本没启动，报 `Error: listen EACCES: permission denied ::1:5173`。
- 根因：本机 Windows 保留端口段 5142–5241（Hyper-V/WSL 常见），5173 和 5174 均落在其中，普通进程无法绑定；报 EACCES 而非 EADDRINUSE。用 `netsh interface ipv4 show excludedportrange protocol=tcp` 可查。
- 修复：在 `vite.config.js` 中加入 `server: { port: 5300 }`。
- 验证：`npm run dev` 输出 `http://localhost:5300/`，curl 返回 HTTP 200。
- 注意：本机 5173/5174 不可用；后续新项目若沿用默认端口需同样改端口。
